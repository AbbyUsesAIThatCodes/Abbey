# Candlelight art-study review

**Version:** 0.0.1 · Candlelight  
**Date:** 13 September 2026  
**Scope:** The three narrow animated visual studies described by the founding design.

## What exists

A dependency-free preview contains three original SVG drawing treatments of one abbey clearing. All three share the same site plan, seed, clock, camera, routes, people, weather, and construction stages. They differ in tree silhouettes, line weight, detail, palette, roof treatment, and illustration.

The clearing contains a chapel, kitchen, well, garden, material stores, wheelbarrow, stream and bridge, surrounding trees, and one evolving stone bay. The timber bell frame swings during the call to Vespers. Figures walk, carry supplies, work, gather, observe, and disperse. Trees sway, chimney smoke rises, precipitation moves, fog drifts, and lights appear at dusk.

The twelve visible brothers are test figures. Six are from the proposed founding cast; six are clearly marked “Study extra” in the inspector. This does not expand the eight-person scope of First Bell or replace the planned lay workers.

The event illustration and sample choices demonstrate a possible visual and writing vocabulary. They do not implement resource costs, relationships, eligibility, or a branching narrative engine.

## Comparison

| Direction | Observed visual strengths | Questions still to answer |
| --- | --- | --- |
| Orchard Cloister | Strong separation between people, buildings, and foliage; clear masonry and warm roofs | Can later architecture gain enough individual character while retaining the simple forms? |
| Living Manuscript | Distinctive foliage, jewel accents, strong ink vocabulary, compatible illustrated margins | Does the ornament become tiring in a larger settlement? Should it be concentrated in events and the chronicle? |
| Sunlit Storybook | Softer silhouettes and a gentle palette; coherent warmth across figures and buildings | Will softer edges remain legible at low zoom and under weather on the user's display? |

These are visual judgments, not measured user-preference scores. The initial recommendation remains Orchard Cloister for the moving world, with some manuscript influence in events. No direction is selected on the user's behalf.

## Construction study

The six stages are survey, foundations, walls, arches/scaffolds, partial timber roof, and completion. Incomplete masonry has an open interior and visible temporary works. This is a geometric visual sequence; materials, labor, structural checks, and staged usability are not yet simulated.

The scene has depth ordering and selected-character foliage fading. Building roof cutaways, navigation around arbitrary player buildings, and native renderer occlusion remain later feasibility work.

## Current asset contract

- SVG source is generated by the readable functions in studies/art.js; exported frames also contain ordinary editable SVG paths.
- Scene viewBox: 0 0 1280 850. Fixed projection: screen x = 640 + 36(x − y); screen y = 134 + 18(x + y) − height.
- A figure's local origin is its feet. A tree's local origin is its trunk at ground level. Building footprints use explicit world x/y/width/depth parameters.
- Definition IDs are prefixed by direction, keeping comparison scenes and exported SVG references independent.
- Palette, stage names, and character descriptions are centralized. Weather uses overlays and state changes rather than three complete copies of every asset.
- Effects use shapes, opacity, and ordinary linear/radial gradients. There are no SVG blur filters, external fonts, fetched images, or runtime network requests.
- The tree snow layer is intentionally simplified. Seasonal foliage changes, wind-driven snow accumulation, and sophisticated wet materials are not implemented.
- Artwork and writing were authored for this project. No third-party image or recording is bundled. Do not infer a redistribution license for the whole repository from this provenance note.

Before native implementation, extract a small asset manifest with stable building and portrait IDs, importer support, bounds, scaling, anchor, and variant metadata. A generated full-scene SVG is a useful review export; it is not yet a finished production atlas pipeline.

## Captures

The capture script executes the real art, scene, and app sources in a small deterministic DOM fixture, serializes the resulting SVG, then rasterizes it with Sharp/libvips. The files are direct renders of implementation output, not concept images or browser screenshots.

| Capture | Purpose |
| --- | --- |
| orchard-day / manuscript-day / storybook-day | Matched daylight comparison |
| orchard-night | Readability and pools of lamplight |
| manuscript-snow | Roof/ground accumulation and character separation |
| storybook-fog | Softened distance and foreground visibility |
| orchard-rain | Rain cues and unfinished construction |
| vespers.mp4 | Actual routine rendered at 3× into a twelve-second animation sample |

All still captures use the same work time. The weather and construction alternatives deliberately vary their labeled parameters. The comparison sheet's first row is the matched daylight comparison; its second row shows representative weather/light states.

The comparison JPEG and animation sample are committed. Individual SVG and PNG captures are reproducible outputs of the capture script and are excluded from git to avoid duplicating the same scene seven times.

## Verification record

On 13 September 2026:

- All JavaScript files passed Node syntax checking.
- The standalone bundle was checked against its exact source inputs and contains no runtime network dependencies.
- Ten deterministic checks passed, covering the real controls and shared scene behavior.
- Exported SVGs parsed successfully, retained their definition references, and contained no non-finite coordinates.
- Daylight views for all three directions and representative night, snow, fog, and rain views were rendered and inspected.
- Inspection led to an open masonry interior, softer fog boundaries, a bridge that spans the stream, physical lanterns at light sources, and foliage fading around selected figures.

**Browser verification remains outstanding.** The Cloud Browser rejected navigation to the local HTML under its URL security policy. No alternate browser access path was used after that rejection. The DOM fixture is not a browser and does not validate CSS layout, browser pointer targeting, keyboard focus order, file-download behavior, or actual animation performance. There is no measured 60-fps result and no native renderer benchmark.

The included frame panel lets the user obtain local timing. When recording a result, note the browser, OS, CPU/GPU, viewport and zoom, chosen style/weather, number of visible studies, and whether the stress scene is enabled.

## A short review session

1. Open Candlelight.html and watch the default scene for a moment.
2. Change between the three styles without restarting.
3. Compare night, snow, and fog, paying attention to the brothers and the unfinished bay.
4. Call Vespers and watch the complete routine. Try pause and the slower pace.
5. Compare the event illustration and a close-up portrait in each style.
6. Save a frame of the direction you prefer, or describe which parts you would combine.

Before considering the browser preview fully verified, check the character click target, pan/zoom, SVG download, event dialog dismissal, and layout in a narrow window on the user's browser.
